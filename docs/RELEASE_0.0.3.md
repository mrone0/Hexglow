# Hexglow 0.0.3

当前为本地候选版，真实游戏性能仍待复测。

- 自动推荐及模型配置在重启、升级后恢复；每轮最多 4 次，不设每日总上限，旧每日限额不再拦截。
- Jev 聚焦当前对局，缺少阵容也可分析；评分最高的有效候选标记为综合推荐。
- 选人时提前准备 OCR、知识库与侧栏；首轮等待实际开局 API 事件，不按加载时间推测，不额外等 3 级或阵容。
- OCR 未就绪时不截屏、不排队等初始化锁，显示预热状态并快速检查；初始化失败明确提示。
- 已处理候选改用轻量标题变化监测，保留定期完整检查及刷新后的两次识别；显式配置 CPU，去重侧栏窗口操作，减少重复负载。掉帧改善仍待实测。
- 首轮识别减负：只检查前台游戏窗口，OCR 使用低优先级单线程，补充典型尺寸合成预热与等待原因日志。
- 按海克斯等级阶段唤醒 OCR：新阶段立即扫描，刚出现的面板短时漏读保持快速复核，持续缺失后降频；推理本身耗时另计。
- 新增像素级面板探测，减少无面板画面的完整 OCR；不确定样式保留回退，探测与实际识别分别统计。
- 无候选线索时不再逐帧追加昂贵的 Small 回退；发现标题立即精读，另保留定期安全回退，减少空帧阻塞。
- 扩大横向采样范围，修复偏左卡片标题被裁掉的问题；识别时遮挡自有侧栏重叠区域，防止重复名称干扰。
- OCR 只读海克斯标题，必要时只在三张卡片内部回退；未定位到卡片时不识别周围游戏文字。
- 修复微小偏移及遮挡边界导致的区域漏判，增加卡片内部回退；定位不确定不再误关侧栏，旧分与推荐暂隐藏，确认后恢复。
- 修复选完后侧栏长时间遮挡：区域持续未确认且无鼠标交互时，约 3 秒折叠成把手，保留结果；不是已选完判定，不重试模型。一般无交互折叠仍为 20 秒。
- 优化设置页、候选卡片和知识编辑体验；新增一键本地打包命令。

覆盖安装前先“完全退出”，选择原目录。知识库、档案、设置及已保存密钥会保留；同版本修复包需要手动覆盖安装。
