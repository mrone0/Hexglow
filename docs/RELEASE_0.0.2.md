# Hexglow 0.0.2

本版增加自动模型推荐和密钥持久化，修复评分已生成但侧栏未展开的问题。

## 更新

- 稳定识别完整候选后自动分析，需配置模型并授权；本版自动推荐默认关闭。
- 同组不重复自动请求，每轮最多 3 次，与手动分析共用每日上限。
- API Key 保存在 Windows 凭据管理器，重启及正常升级后恢复。
- 模型分析期间继续跟踪对局，过期结果不弹回当前候选。

## 安装

下载 `Hexglow_0.0.2_x64-setup.exe`，先“完全退出”，再选择原目录覆盖安装。知识库、档案和设置会保留。

此前同为 0.0.2 的安装包需手动覆盖一次，同版本不会触发自动更新。旧版未保存过的 Key 需重新填写。

模型比较分不是胜率；本版当时尚未完成真实模型端到端验收。
