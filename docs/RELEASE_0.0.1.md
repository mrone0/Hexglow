# Hexglow 0.0.1

面向 Windows x64 的首个公开版本：本地识别海克斯候选、按需进行模型推荐、保存对局档案，并用中文表单维护个人知识库。

## 本版功能

- 自动发现本地客户端并跟随大厅、选人、对局和结算状态；离线 OCR 模型随安装包提供，识别本身无需 API Key，也不会触发收费分析。
- 模型依据当次英雄、装备、双方阵容、已选海克斯、完整候选效果及检索到的知识动态比较，不混入固定英雄/海克斯适配分。主窗口和悬浮侧栏共享同一份有效模型结果。
- 知识工坊默认使用中文表单：修改名称、说明和各段知识后保存，不必手写 Markdown、YAML 或内部编号。保留高级编辑、导入、原有自定义章节和未保存保护。
- 保存对局、候选、实际选择及分析依据，支持档案查询、复盘和导出；档案详情的返回列表入口位于页面左上角。
- 结算补录按精确对局 ID 和可信玩家身份合并官方证据，拒绝串局及矛盾结果。客户端未提供的字段保持未知，不补造胜负或海克斯。
- 单实例、系统托盘及保存后完全退出。主窗口右上角“×”只隐藏窗口，应用仍在后台运行。

## 安装与升级

1. 下载本 Release 的 `Hexglow_0.0.1_x64-setup.exe`。如旧版仍在运行，先点击应用内“完全退出”保存数据。
2. 首次安装按提示进行；已有安装请选择添加/重新安装并沿用原目录，无需先卸载，不要勾选删除应用数据。
3. 正常覆盖安装及内置更新保留应用数据目录中的知识库、对局档案和设置。API Key 仅保存在运行内存中，退出后需重新输入。
4. 如果尚未安装 WebView2，安装器会联网获取它。请使用完整安装包，单独复制应用 EXE 会缺少离线 OCR 资源。

后续发布更高版本后，可在“设置 → 应用更新”检查、下载并安装，安装前先保存对局，再退出应用启动安装程序。**同为 `0.0.1` 的旧候选包不会收到本次同版本更新**；如尚未安装最终版，请手动覆盖一次。版本号高于 `0.0.1` 的早期开发包也不会自动降级。

更新前请保存知识编辑，并在下载/安装期间留在设置页，不再编辑资料。当前更新安装流程会保存对局，但没有覆盖下载期间新产生的未保存知识编辑，不应依赖更新操作代替手动保存。

本 Release 附带 `.sig`、`latest.json` 与 `SHA256SUMS.txt`。应用使用内置公钥验证更新签名；私钥不包含在发布资产中。Tauri 更新签名不是 Windows Authenticode 发布者证书，安装器目前没有该证书，Windows 仍可能显示未知发布者或 SmartScreen 提示。

## 使用边界与隐私

- 自动 OCR 要求游戏窗口处于前台、可见且未最小化；识别不可靠时可手动纠正。日志中的 `matched=3` 只证明识别链路运行，不代表逐字准确或全场景覆盖。
- 推荐需用户配置模型服务并授权、主动发起。外部服务可能收费；知识缺失和模型判断仍会影响结果。分数是相对契合度，不是胜率，也不保证最优选择。
- 内置知识种子和模型置信度尚未经过系统实战校准；用户可以通过表单持续补充英雄机制和搭配经验。知识保存不自动调用模型，后续主动分析时读取更新。
- 赛后接口可能拒绝请求或仅返回部分数据；历史列表 HTTP 400 的兼容性仍待真实环境进一步验证。已有条目“已核实”不等于全员、全轮次齐全。
- 对局数据保存在本机，数据库没有额外加密。模型外发会去除原始接口载荷、玩家名称及对局 ID，但自由文本仍可能包含个人信息，请自行检查。

## 验证范围

本地验证：376 项前端/脚本测试、177 项 Rust 测试通过；1 项要求可见真实游戏窗口的测试未执行。TypeScript/Vite、Rust 格式检查、锁定依赖 Windows 打包、离线 OCR 资源和本地更新签名校验通过。公开资产另由 GitHub Actions 构建并验证。

已有真实对局日志和数据库证据覆盖部分候选轮次及直接结算落库，但不等于当前所有改动均完成安装后端到端验收。活动对局退出、线上自动更新、真实外部模型、全部分辨率和游戏补丁等场景仍需继续验证；本版发布不声称全场景无误或百分百识别。
